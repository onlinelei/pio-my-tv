# myTV 后台管理系统设计方案

> 本文档为 myTV 多屏显示系统的 **Java 后台 + 管理前端** 设计文档。
> 设备端固件设计请参阅 [myTV系统设计方案.md](./myTV系统设计方案.md)。

技术栈：Spring Boot 3 + MyBatis-Plus + EMQX + MySQL + Redis

---

## 后台架构设计

### 后台时间服务（后台自身 NTP 校时，下发给设备）

- 服务器通过 chrony/systemd-timesyncd 保持时间精确
- 设备上线时，在 MQTT 响应中下发 `cmd/time` 消息
- 定时广播 `cmd/time`（如每小时一次）校准所有设备

### 后台天气服务（后台查询第三方 API，缓存后推送给设备）

- 根据设备上报的 `city_id` 查询和风天气/心知天气
- 缓存 30 分钟，同城市多设备共享缓存
- 通过 MQTT `cmd/weather` 推送给对应设备

### 模块规划

1. **设备管理模块** - 设备注册/分组/批量配置
2. **MQTT 通信模块** - 消息发布/订阅/设备在线检测
3. **时间服务模块** - NTP 校时 + 时间下发设备
4. **天气服务模块** - 第三方 API 查询 + 缓存 + 推送
5. **内容管理模块** - 推送文字/图片/视频，定时播放列表
6. **远程管理模块** - 重启/亮度/音量/OTA 触发
7. **音频服务模块** - 录音上传接收/存储/ASR转写/实时流转发
8. **数据统计模块** - 在线统计/交互分析/故障日志
9. **用户管理模块** - 登录/权限/多租户
10. **告警模块** - 设备离线/温度异常/内存不足 告警

### API 接口规划

```
# 设备管理
POST   /api/devices                              - 注册设备
GET    /api/devices                              - 设备列表

# 设备远程控制
POST   /api/devices/{id}/cmd/reboot              - 远程重启
POST   /api/devices/{id}/cmd/display             - 推送显示内容
POST   /api/devices/{id}/cmd/brightness          - 调节亮度
POST   /api/devices/{id}/cmd/notify              - 推送通知
POST   /api/devices/{id}/cmd/ota                 - 触发 OTA

# 音频管理
POST   /api/devices/{id}/cmd/audio/record        - 下发录音指令
POST   /api/devices/{id}/cmd/audio/stream        - 开启实时流
POST   /api/devices/{id}/cmd/audio/stop          - 停止录音/流
POST   /api/audio/upload                         - 设备上传录音文件 (multipart)
GET    /api/audio/{deviceId}                     - 查询设备录音列表
GET    /api/audio/{deviceId}/{recordingId}       - 下载/播放录音
DELETE /api/audio/{deviceId}/{recordingId}       - 删除录音
WS     /ws/audio/stream                          - 实时音频流 WebSocket

# 设备状态 & 日志
GET    /api/devices/{id}/status                  - 查询设备状态
GET    /api/devices/{id}/logs                    - 查询日志

# 统计 & 广播
GET    /api/stats/online                         - 在线统计
POST   /api/broadcast                            - 紧急广播（所有设备）
```

## 后台管理页面规划

### 前端技术栈

| 技术 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue 3 + TypeScript | 单页应用，Composition API |
| UI 库 | Element Plus | 成熟的后台 UI 组件库 |
| 图表 | ECharts | 实时监控图表 |
| 地图 | 高德地图 | 设备地理分布（可选） |
| 构建 | Vite | 快速构建 |
| 状态 | Pinia | 全局状态管理 |
| 路由 | Vue Router | 页面路由 |
| HTTP | Axios | API 请求 |
| WebSocket | 原生 / Socket.IO | 实时音频流 + 设备状态推送 |

## 时间与天气数据流

```
后台服务器
    ├─ chrony/NTP 保持系统时间精确
    ├─ 定时查天气 API（和风天气），缓存 30 分钟
    │
    └─ MQTT 下发给设备
        ├─ cmd/time    {timestamp, timezone}    ← 上线时 + 每小时
        └─ cmd/weather {city, temp, humidity..} ← 上线时 + 每 30 分钟
              │
              ▼
        ESP32 设备端
        ├─ TimeManager::setTime() → 本地 millis() 推算走时
        ├─ WeatherCache → InfoPanel 读取显示
        └─ 断网时: millis() 继续走时，天气显示最后缓存
```
